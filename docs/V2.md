
# V2 — Monitoramento de Sensores

## Objetivo

Adicionar sensores ao projeto e disponibilizar suas leituras em uma interface web.

## Novos componentes

- DHT22 para temperatura e umidade.
- Potenciômetro para entrada analógica.
- ESP32 e circuito de LED da V1.

## Conceitos estudados

- Leitura digital do DHT22 por biblioteca.
- Leitura analógica com `analogRead()`.
- ADC de 12 bits no ESP32 clássico.
- Formato JSON.
- Endpoint HTTP `/data`.
- JavaScript e `fetch()`.
- Atualização periódica da interface.

## Rotas HTTP

- `/`: página principal.
- `/data`: dados dos sensores e estado do LED.
- `/toggle`: alternância do LED por requisição HTTP POST.
