
# V1 — Servidor Web e Controle de LED

## Objetivo

Criar uma rede Wi-Fi própria no ESP32 e disponibilizar uma interface web para controlar um LED pelo navegador.

## Conceitos estudados

- Wi-Fi em modo Access Point (SoftAP).
- Servidor HTTP com `WebServer`.
- Rotas HTTP.
- HTML e CSS.
- Controle de GPIO.
- Requisições e respostas HTTP.

## Hardware

- ESP32.
- LED.
- Resistor de 220 Ω ou 330 Ω, caso seja usado LED externo.
- Protoboard e jumpers.

## Funcionamento

O ESP32 cria a rede Wi-Fi `ESP32-IOT` e hospeda a interface web em `192.168.4.1`.

A rota `/` apresenta o painel. A rota `/toggle` alterna o estado do LED.
